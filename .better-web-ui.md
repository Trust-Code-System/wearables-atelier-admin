# Admin design context

Wearables Atelier administrators manage the catalog, orders, sales overview and store settings. The user explicitly chose the original ObsidianUI dashboard shell: Inter text, neutral dark/light panels, blue primary controls, duotone icons, responsive sidebar/drawer and purposeful motion. Retain the original Wearables by Ashabi logo and local brand photography. Preserve keyboard controls, visible focus and reduced motion.

The admin app is a separate Next.js 16.4/React 19 project and public Git repository. The customer storefront is a separate project at its configured external URL. Root `/` redirects to `/admin`; existing admin paths stay compatible. Data currently uses browser storage and does not sync with the storefront. The owner explicitly deferred the shared backend to the next phase.
